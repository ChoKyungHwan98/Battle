# Crunch AI 폴리싱 — 구현과 플레이 확인 구분

기준: 2026-10-06, 행동 데이터는 Unreal Editor에서 직접 조회했다.
현재 AI 연결은 구현했지만, **제출 가능한 완성 상태는 아직 확인하지 못했다.**
사용자의 요청에 따라 이번 변경에서 에이전트가 PIE를 실행하거나 화면을 평가하지 않았다.

**이후 사용자 확인: 중거리 공격 경험 실패.** 사용자는 400~500cm에서 공격을 시작하지
않고 움직임만으로 피할 수 있다고 평가했다. 기존 중거리 흐름은 완료로 취급하지 않는다.
[중거리 전진 공격 재설계](crunch_midrange_strike_redesign_20261006.md)를 다음 구현 기준으로 삼는다.

## 원하는 경험과 현재 증거

| 원하는 경험 | 구현 또는 확인한 것 | 아직 증명하지 못한 것 |
|---|---|---|
| 400~500cm에서 디디며 공격을 감행한다 | 현재는 350cm 이내로 먼저 접근하는 실행. 사용자 평가로 의도 불충족 확인 | 중거리에서 곧바로 공격 준비를 시작하는 전진형 제작·접촉·보행 후퇴 압박 |
| 느리고 무거운 주먹이 발과 함께 나간다 | 일반 펀치 발 곡선과 이동 연결, 앞 대기 0.08초, 재생속도 0.75 | 발 접지·진입 감속·모션 전환·실제 주먹 접촉 |
| 실패한 추격을 끝없이 반복하지 않는다 | 2초 진입 제한, 실패 기술 감점, 6초 내 2회 실패 후 0.65초 관찰 | 실제 추격 시간과 반복 횟수 감소, 관찰이 잦아 허수아비처럼 보이지 않는지 |
| 공격 후 같은 행동만 반복하지 않는다 | 다음 공격 선택 후 조건부 25% 옆걸음. 한 번만, 목적지 고정, 4초 재사용 대기 | 평지에서 좌우 이동과 직접 공격이 자연스럽게 섞이는지 |
| 막힌 길에서 다른 자리를 찾는다 | 공격 범위 안의 좌우 목적지, 전체 경로 캡슐 검사, 도착 후 재확인 | 벽 근처에서 길 막힘·왕복·미끄러짐이 없는지 |
| 단타·2타·3타와 특수 공격이 구분된다 | 10개 행동 데이터, 2타 연결/중단, 원래 3타 유지, 점수 최종 합산 | 실제 빈도·휩쓸기 활용·2타의 두 번째 공격 완주·특수 공격 접촉 |
| 반격 기회가 공정하다 | HFSM 후딜 규칙, 2타 중단 회수 0.85초 | 마지막 손 판정 뒤의 실질 빈틈 및 플레이어 2~3타 가능 횟수 |
| 기획자가 선택 이유를 설명할 수 있다 | 전체 후보 점수 HUD, 쉬운 이동/중단 이유, QA 기록과 설명서 | 실제 화면 가독성, 새 행동별 QA 증거 |

빌드 성공과 네이티브 자동화 6개는 계획 계산·선택 조건·상태 전환 인자를 확인한다.
블루프린트 연결 재조회는 실행 경로를 확인한다. 둘 다 실제 플레이의 자연스러움이나
모든 기술의 사거리를 입증하지 않는다. 최신 HUD 이후 `Saved/Logs/Battle.log`에는
이 확인표를 작성한 시점까지 `[BATTLE_QA]` 플레이 기록이 없었다.

## 완료로 표시하면 안 되는 핵심 세 가지

1. **350cm 시작 사거리.** 손 판정을 키우지 않고 디딤 이동과 실제 접촉을 맞춰야 한다.
   진입 로그만으로 이 거리가 맞다고 판단하지 않는다.
2. **반격 시간.** 현재 2연타의 마지막 손 판정 종료부터 행동 종료까지 데이터상
   약 1.85초다. HFSM Recovery 타이머 약 0.97초와 다르다. 사용자가 원한 1초 미만
   일반 반격 구간과 실제 2~3타가 가능한지를 함께 조정해야 한다.
3. **모든 공격 불가 시에만 후퇴.** 현재 선택한 공격의 최소 거리 기반 StepBack과
   기존 spacing 처리가 있다. 과거 v2의 ‘모든 근접 공격의 실제 접촉을 확인한 뒤에만
   CreateSpace’ 정책 전체가 구현됐다고 말하면 안 된다. 접촉 범위 측정이 선행돼야 한다.

## 다음 플레이에서 먼저 볼 네 장면

처음부터 긴 통계 시험을 반복할 필요는 없다. 다음 네 장면으로 큰 문제부터 찾는다.

1. **중거리에서 천천히 뒤로 걷기:** 계속 달리기만 하는지, 발을 디디며 주먹을 내는지,
   주먹이 몸에 닿았는데도 빗나가는지 본다.
2. **공격을 피하고 가까이 남기:** 마지막 판정이 끝난 뒤 반격해 본다. 몇 타가 들어가고
   보스가 언제 다시 움직이는지 본다. 2연타의 중단 회수도 확인한다.
3. **공격 후 약간 거리를 유지하기:** 다음 공격을 바로 하는 경우와 짧은 좌우 옆걸음 뒤
   공격하는 경우가 섞이는지 본다. 드문 행동이 한 번 안 나왔다고 고장으로 단정하지 않는다.
4. **벽을 등지고/옆에 두고 움직이기:** 지나갈 수 없는 곳으로 계속 밀거나, 측면 위치를
   반복 변경하거나, 너무 자주 관찰하며 멈추는지 본다.

플레이를 마친 뒤 ‘로그 봐줘’와 체감한 문제만 알려주면 된다. 로그는 프로젝트에서
직접 읽는다. 화면이 자연스러운지는 사용자가 판단하고, 로그에서는 실행과 시간·거리의
근거를 확인한다. 큰 문제가 해결되면 v2의 시작 10회·원거리 30회·좌우 뒤쪽 각 5회·
밀착 10회·회피 반격 10회·공격 후 20회 판단을 모아 최종 제출 증거로 사용한다.
