# MotionLab — 기본 주먹과 한 발 전진 비교

대상: `/Game/BossArena/Maps/Lvl_BossMotionLab`. 2026-10-06 변경.
실험실의 동일한 주먹 모션에서 몸 전진을 꺼 보거나 한 발 전진을 고정해서 비교한다.
이동 방식의 시험 설정은 실험실에만 적용되며 Arena의 자동 전투 규칙은 유지한다.

## 조작

| 조작 | 동작 |
|---|---|
| L | 실전 자동 → 기본 제자리 → 한 발 전진 순서로 전환 |
| 1 / 2 | 선택한 방식으로 왼손 / 오른손 주먹 실행 |
| Z / X / N / V / B / M | 175 / 300 / 350 / 400 / 500 / 1000cm로 위치 초기화 |
| R | 선택한 거리로 위치 초기화. 주먹 방식은 유지 |
| 3~9, 0 | 기존 어퍼컷·휩쓸기·3타·가드 깨기·슈퍼맨·접근·점프·2연타 |
| Tab | 조작법 표시 |
| H | 판정 표시 전환 |
| [ / ], O, C | 기존 원본 모션 탐색·피해 없는 미리보기·목록 전환 |
| T / Y / U / I | 기존 회수 및 대시 연결 비교 |

새 세션은 175cm, 실전 자동으로 시작한다. 방식을 바꾸면 선택한 거리로 다시 배치한다.
공격이 진행 중일 때 L은 거부한다. 거리 초기화는 기존처럼 동작을 중단하는 테스트 조작이다.

## 세 방식의 의미

- **실전 자동:** Arena와 같은 거리별 한 발 계산. 근접은 원래 요청 이동량을 쓰고,
  300~400cm에서는 짧은 후퇴 보정과 145cm 상한을 적용한다.
- **기본 제자리:** 왼손·오른손의 몸 전진 요청을 0으로 둔다. 주먹과 다리 포즈 자체는
  같은 모션을 재생한다. 모션의 팔 궤도와 몸 전진의 영향을 비교하는 기준이다.
- **한 발 전진:** 남은 예산 안에서 최대 145cm의 한 번 전진을 요청한다.
  실제 이동은 밀착·벽·충돌에 따라 더 짧아질 수 있다. 145cm 이동을 보장하지 않는다.

세 방식 모두 실전 손 판정과 피해·후딜을 사용한다. 행동 시작의 거리·상태·쿨다운
검사를 우회하지 않는다. 따라서 기본 주먹은 500cm에서 거부된다. 이를 확인할 때는
500cm를 설정하고 1/2를 눌러 거부를 확인하거나, 7을 눌러 슈퍼맨을 확인한다.

## 쉽게 비교하기

1. N으로 350cm를 설정한다.
2. L로 ‘기본 제자리’를 골라 1을 누른다. 팔만 뻗는 도달 범위를 본다.
3. 공격과 플레이어 반응이 끝나면 L로 ‘한 발 전진’을 고른다. 같은 350cm로 배치된다.
4. 다시 1을 눌러 몸이 실리는 모습과 손 접촉을 비교한다.
5. R로 위치를 맞추고 2로 오른손도 확인한다. 300/400cm에서도 반복한다.
6. L로 ‘실전 자동’에 돌아가 같은 거리에서 실제 전투의 전진량을 확인한다.

화면은 현재 주먹 방식, 이번 공격 방식, 실제 몸 전진 거리, 요청 전진량, 손 접촉 시각,
판정 시작과 피해 횟수를 보여준다. 손 접촉 기록은 왼손·오른손에 각각 적용한다.
로그의 `MotionLab request` 및 `MotionLab punch` 행에는 mode, requestedStep,
bodyTravel과 실제 선택한 손 이름이 남는다.

‘손 접촉’은 손 위치와 플레이어 캡슐의 근접 측정이며 피해 이벤트와 동일하지 않다.
피해 횟수를 별도로 본다. 몸 전진은 공격 시작 위치에서의 수평 변위이며 전체 이동 경로
길이를 합산한 값이 아니다. 실제 표시와 입력·명중은 사용자 플레이 확인이 필요하다.

손 표시와 접촉 측정의 반경도 현재 실제 값인 `PhysicalHandRadiusLocal × |ActorScale.X|`
에서 읽는다. 이전 고정 52cm 표시를 제거했다. 배치 크기 1.3, 로컬 반경 55cm이면
71.5cm로 표시한다. 실제 피해 판정의 크기를 새로 키운 변경은 아니다.

검증: 최종 네이티브 빌드 성공(2026-10-06 08:05 UTC), MotionLab 맵과 배치
Director→보스 연결 확인. AutomationTestToolset으로 발견·실행·결과 수집한
비교 모드 검사와 기존 AI 계산 검사 8개 모두 오류·경고 없이 성공했다.
비교 검사는 제자리 0, 유한 전진, 남은 예산 제한, Arena에서 실험실 설정 무시를 다룬다.
실제 키 입력·화면·접촉은 검사하지 않았다.
