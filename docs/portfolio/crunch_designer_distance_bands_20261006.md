# Crunch — 사용자가 정한 거리별 행동과 Space 달리기

후속 반영: [실험실 디딤의 실전 연결과 어퍼컷·휩쓸기 다양화](crunch_combat_variety_20261006.md).
300~400cm 일반 주먹은 이제 랩에서 확인한 145cm 요청을 공통으로 사용한다.
아래의 시작 거리별 보정 설명은 이전 시험값이며 후속 문서를 우선한다.

MotionLab에서 기본/한 발 전진을 따로 비교하는 조작은
[실험실 비교 안내](crunch_motion_lab_punch_comparison_20261006.md)를 참고한다.

2026-10-06 최신 지시. 이전 400~500cm 전진 주먹 재설계보다 이 거리 구분을 우선한다.
거리는 보스와 플레이어의 캐릭터 중심 사이 cm다. 배치 크기는 이번 변경에서 바꾸지 않았다.

## 플레이어가 경험할 행동

| 거리 | 행동 역할 | 이번 적용 |
|---|---|---|
| 약 175cm, 몸이 붙은 거리 | 기본 주먹과 어퍼컷 사용 | 왼손·오른손 최소 165cm, 어퍼컷 재활성화 및 165~250cm 후보 |
| 약 300~400cm | 한 발 내디디며 일반 주먹 | 시작 상한 350→400cm. 별도 접근 없이 공격 시작 가능. 공격 안의 단일 전진량 조정 |
| 400cm 초과~500cm 미만 | 일반 주먹을 시작할 자리까지 짧게 연결 | 기존 의도 유지 진입 사용. 500cm 사거리 주먹으로 확대하지 않음 |
| 500~1000cm | 슈퍼맨 펀치 또는 접근 | 돌진 후보 범위 400~900→500~1000cm. 기본 주먹·2타의 먼 거리 진입 후보 제외 |
| 1000cm 이상, 2페이즈 | 점프 공격 후보 | 반복 점프 카드의 1000~5000cm 조건 유지. 2페이즈 첫 점프도 거리 조건 적용 |

거리마다 단 하나의 공격을 강제하는 표가 아니다. 예를 들어 500cm에서 슈퍼맨의
점수와 접근의 점수가 함께 남는다. 기존 반복 감점·쿨다운·경로 검사·첫 판단 제한을
계속 적용한다. 밀착에서는 2타·3타·휩쓸기 등 기존 각 공격 조건도 유지한다.

## 한 발 디딤의 변경

왼손·오른손 모션과 발 이동의 시간 곡선을 유지한다. 300cm 미만에서는 기존 요청량
(약 66/87cm)을 사용하고, 300~400cm에서는 시작 거리와 짧은 후퇴 보정을 반영하되
**한 번의 요청 이동량 상한은 145cm**다. 145cm는 실제 이동 실측값이나 확정 기획값이
아니며 첫 시험값이다. 밀착·벽에서는 기존 몸 접촉 여유 및 충돌 검사가 전진을 제한한다.

발 이동을 시작할 때 계산한 전진량을 변수에 저장하고, 공격 중에는 같은 값을 사용한다.
매 프레임 플레이어를 쫓아 전진량을 더하지 않는다. 일반 주먹을 위한 전진 예산도
95→145cm로 맞췄다. 몽타주에 달리기/두 걸음 클립을 앞에 붙이지 않았다.

이번 변경은 400cm에서 공격을 시작하도록 막혀 있던 실행과 전진량을 수정한 것이다.
몸 전진이 커진 만큼 **발 접지·미끄러짐·실제 손 접촉은 사용자 화면 확인이 필요하다.**
특히 걷기 후퇴의 모든 속도·각도를 반드시 맞힌다는 결과는 아직 검증하지 않았다.

## 밀착 어퍼컷

비활성화됐던 `DA_Attack_Uppercut`을 활성화했다. 독립 단타 모션은 기존
`Ability_Combo_03` 왼손 어퍼컷이며, 점프하는 `Ability_Uppercut`을 사용하는 기존
3연타와 구분한다. 손이 아래에서 올라오는 구간을 본 포즈로 확인하고 판정 종료를
모션 시간 0.30→0.24초로 당겼다. 시작은 0.15초, 재생속도 0.6이므로 행동 시간 기준
약 0.25~0.40초가 타격 구간이다. 손이 머리 위로 올라간 뒤의 판정을 줄이는 목적이다.
피해량·손 판정 크기는 확대하지 않았다. 이 포즈 확인은 실제 명중 시험을 대신하지 않는다.

## 첫 점프와 일반 전투가 충돌하지 않도록

기존에는 2페이즈 첫 점프만 거리를 무시했다. 이제 첫 점프도 1000~5000cm 안에
있을 때 실행한다. 가까이 있으면 예정 표시는 남겨두고 일반 전투를 계속한다.
점프 우선순위 검사와 실행 함수에 같은 조건을 연결했다. 실행 함수만 막아두면
가까운 보스가 매 판단마다 점프를 시도하고 멈출 수 있으므로 두 위치를 함께 수정했다.
2페이즈 조건과 현재 공격을 마친 뒤 실행하는 규칙은 유지한다.

## Space 달리기 모션

플레이어 `bIsSprinting`을 AnimBP의 `bSprintPose`에 매 업데이트 전달한다.
현재 BlendSpace의 0=대기, 300=걷기, 600=달리기 행을 명시적으로 이용한다.

- 평상 이동: 실제 속도 450cm/s에서 애니메이션 입력은 300(걷기 행).
- Space 달리기: 실제 속도 650cm/s에서 입력은 600(달리기 행).
- 가속 중에는 실제 속도에 비례해서 자세가 섞이고, 정지하면 입력은 0이 된다.
- 달리기는 기존 `Sword_RunFwd`와 방향별 Run 모션을 쓴다.

이동 속도 450/650, 입력 Hold 판정, 락온 복구와 회피 입력은 이번에 바꾸지 않았다.
바뀐 것은 Space 달리기 상태가 모션 선택에 전달되는 연결이다. 평상 걷기와 캡슐
속도의 발 일치, 가속 중 전환 품질은 사용자 확인 대상이다.
