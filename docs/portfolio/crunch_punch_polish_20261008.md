# 1번 사거리 조정 / 2번 디딤 공격 연결 보정

목표: 사용자가 대략 승인한 1번 디딤 공격의 형태를 유지하며 실제 도달 거리를 확인하고, 2번은 시작과 착지 연결을 다듬는다. 550cm를 무조건 달성하는 대신 자연스러운 디딤으로 가능한 범위를 측정한다.

## 기획자가 볼 결과

| 공격 | 바꾼 것 | 실제 시험 결과 |
|---|---|---|
| 1번 왼손 | 오른발 디딤과 펀치를 유지하면서 몸 전진량을 약 72cm → 117cm로 조정. 대기 자세에서 시작하고, 공격 후 지지발을 조금 일찍 정돈한다. | 400 / 425 / 450cm 명중. 460 / 475cm 빗나감. **현재 권장 최대 450cm.** |
| 2번 오른손 | 대기 자세에서 준비 자세로 연결. 착지 부근 허리 높이가 급하게 바뀌는 부분을 완화. 추가 발걸음이나 펀치 지연은 넣지 않는다. | 350 / 375 / 385cm 명중. 395 / 400 / 420cm 빗나감. 실험실 최대 거리를 **385cm**로 정정. |

거리는 **공격 시작 시 보스와 플레이어의 중심 간 수평 거리**다. 현재 MotionLab의 보스 배율 1.3, 기존 플레이어 충돌 크기와 주먹 접촉 판정을 사용했으며, 정지한 플레이어를 대상으로 측정했다. 이동·회피 중 명중 보장은 아니다. 경계 안의 모든 cm를 검사한 것도 아니다.

550cm를 이 동작에 그대로 요구하면 바닥에 버티는 다리가 과하게 펴진다. 발을 더 멀리 내딛고 몸의 지지 구조를 바꾸는 별도 동작 설계가 필요하다. 허공까지 공격 범위를 키우거나 몸만 슬라이드시키는 방식으로 사거리를 늘리지 않았다.

## 왜 2번 연결을 바꿨는가

기존 2번 첫 자세의 오른손은 대기 자세와 약 103cm 떨어져 있어, 공격이 시작되는 순간 손이 튀어 보일 수 있었다. 첫 0.22초(애니메이션 시간)를 대기 자세에서 연결하도록 키를 작성했다. 실제 타격 구간의 상체 회전과 기존 재생 속도는 유지한다.

착지 구간의 허리 높이 변화도 부드럽게 연결했다. 애니메이션에서 측정한 허리 정지 가속도는 약 176 → 109m/s²로 줄었다. 이는 급격한 변화가 줄었다는 기술 지표이며, 자연스럽다는 미술적 승인과는 구분한다.

## 제작과 검증

- Crunch 자체 원본/승인 클립 → 별도 편집용 복제 → Control Rig 키 → Level Sequence → AnimSequence Bake → 별도 Montage → MotionLab 전용 행동 카드.
- 1번 펀치의 상체 회전 오차는 약 0.034도, 2번은 초기 연결 이후 약 0.015도. 베이크 결과의 발 목표 오차는 두 공격 모두 0.02cm 미만.
- 다리 과신전, 지지 중 발끝 이동, 마지막 프레임, Root Motion, FullBody 전신 적용, 기존 타격/FX Notify 보존을 검사했다.
- 실제 게임에서 1번 몸 전진 약 117cm, 2번 약 69cm를 측정했다. 실제 피해는 명중 시 각 110. 오른손 공격은 hand_r를 별도로 기록했다.
- 두 PIE 시나리오가 통과했고 종료도 확인했다. 두 번째 시나리오는 450cm 명중/460cm 빗나감을 피해량으로 재확인했다. 배경 성능 제한과 임시 미리보기 배우/카메라는 복구했다.
- 기존 승인 모션과 이전 후보는 보존했다. 이번 연결 범위는 **MotionLab 전용**이며 Arena의 Utility/GOAP 선택이나 C++는 이번 작업에서 수정하지 않았다.

## 중거리 510cm: 두 걸음 진입 (2026-10-08 오후, 현재 모션랩 연결본)

요구: 1번은 345~510cm, 2번은 331~510cm에서 **상체 공격은 그대로, 하체만 전진**해서 닿아야 한다.
한 걸음 디딤은 땅에 붙인 다리 길이 때문에 몸이 약 90cm(게임 117cm)까지만 나갈 수 있어서 1번 450cm, 2번 385cm가 한계였다.

해결: 두 발이 한 번씩 모두 전진한다. **오른발 한 걸음 → 왼발 한 걸음.** 두 원본 모두 준비 동작 끝에 왼발을 내려놓는다
(1번: 왼손과 함께 왼발을 짧게 내딛음, 2번: 왼무릎 들어 찍기). 그래서 왼발 걸음은 원본의 그 걸음을 길게 한 것이고,
왼발이 착지한 순간부터 하체는 **원본을 전진량만큼 앞으로 옮긴 것과 똑같다.** 타격 자세와 회복 동작을 새로 만들지 않았다.

| | 1번 왼손 | 2번 오른손 |
|---|---|---|
| 전진(애니메이션 / 게임) | 136cm / 177cm | 165cm / 214cm |
| 오른발 걸음 → 왼발 걸음(애니메이션 초) | 0.02–0.17 → 0.17–0.385 | 0.02–0.16 → 0.165–0.36 |
| 명중 실측 | 345 / 400 / 510 / 520cm 명중, 530cm 빗나감 | 331 / 400 / 510 / 520 / 530cm 명중 |
| 검증 | 발 목표 0.008cm, 상체 회전 0.034°, 착지 후 원본과의 차이 0.03cm | 0.009cm, 0.015°, 0.008cm |

- 골반 높이는 손으로 키를 잡지 않고 계산했다. 원본은 두 발을 모으고 높이 서는데 큰 보폭으로는 다리가 닿지 않으므로,
  다리 길이 안에 들어오는 만큼만 낮추고(2번 최대 16cm) 타격 전에 원본 높이로 돌아온다.
- 2번은 게임이 공격 시작 때 보스를 목표에서 15° 틀어 세운다(대각선 휘두르기 조준용). 전진까지 15° 비스듬해져 옆으로 50cm 새고
  510cm에서 빗나갔다. 애니메이션의 전진 방향을 15° 되돌려 정면으로 나가게 했다(옆 밀림 0cm).
- **남은 문제:** 전진량이 고정이라 범위 아래쪽에서는 플레이어 몸에 막힌다(1번은 약 350cm 이하, 2번은 약 390cm 이하에서 시작할 때).
  막힌 동안 발이 제자리에서 미끄러진다. 거리에 맞춰 전진량을 줄이는 처리는 Arena 연결 때 코드로 해야 한다.
- 보폭이 크고 빠르다(발 최고 속도 애니메이션 기준 11~16m/s). **자연스러움은 사용자 QA 대상이다.**

자산: `AS_/LS_/AM_Crunch_LeftSwingRunIn`, `AS_/LS_/AM_Crunch_RightCrossRunIn`. 제작 `Tools/AuthorCrunchRunIn.py`
(`prepare(key) → key_step(key) → bake_validate(key) → integrate(key)`). 이전 카드 연결은 `Saved/VibeUE/Reports/crunch_run_in_key1.json`,
`crunch_run_in_key2.json`의 `previous_card`에 있다(1번 `AM_Crunch_StepThroughReach90_LeftSwing`, 2번 `AM_Crunch_RightCrossHop`).
옆 카메라 촬영: `crunch_key1_runin_20261008.png`, `crunch_key2_runin_20261008.png` (`Tools/TestMotionFilm.py`의 `wide`).

### 5번 잽잽훅도 510cm (같은 날, 사용자가 1·2번 두 걸음 진입을 "아주 좋아"로 확인한 뒤)

- **첫 잽**: 1번과 같은 두 걸음 진입(전진 136cm, 연속기 재생 속도 1.15배에 맞춰 시간만 줄임).
- **2타(오른손)**: 원본이 두 발을 모았다가 왼발을 찍는다. 그 두 걸음을 30cm 길게 했다.

### 거리별 전진량 조절 + 5번 2타·훅 중거리 (같은 날, 사용자 지시)

**규칙(코드, `UBossCombatIntentComponent::UpdateTravelScale`).** 중거리 전진 애니메이션(이름에 `RunIn`)은 가장 먼 거리에 맞춰 만들어져 있다.
몸이 나가기 시작하는 순간, 그 전진 구간의 전진량과 지금 필요한 거리를 비교해 비율을 **한 번** 정한다.

- 비율 = (현재 거리 − 210cm) ÷ 이번 구간 전진량, 0~1로 제한. 210cm는 전진이 끝났을 때 남길 중심 간 거리(훅이 닿는 거리 안쪽)다.
- 구간 도중에는 바꾸지 않는다. 발걸음이 고르게 줄고, 그 사이 플레이어가 물러나면 헛친다(피할 여지).
- 5번은 잽 / 2타 / 훅 진입 / 훅 발 바꾸기, 구간마다 다시 정한다. 그래서 타마다 따라붙는다.
- 자동 시험 `Battle.Boss.TravelScale` 추가. 에디터를 닫고 빌드했다.

**5번 구성.** 2타는 2번과 같은 휘두르기라 2번 중거리(두 걸음 진입, 165cm)를 그대로 넣었다(잽 회복이 끝난 대기 자세에서 시작).
훅은 진입 걸음 100cm + 훅 자체의 발 바꾸기 30cm. 최대 전진 합계 431cm(게임 560cm)이고 실제로는 위 규칙으로 줄어든다.

### 중거리 달려오기, 훅 방침 (사용자 지시)
