# Crunch: 아직 실전 AI에 쓰지 않는 주요 모션

2026-10-05. 현재 공격 카드, 원본 애니메이션의 BossArena 에셋 참조, 애니메이션 그래프 연결을 읽은 기록이다. 플레이 시험은 하지 않았다. 여기서 미사용은 **보스가 자율 전투에서 사용하는 모션에 연결되지 않았다는 뜻**이다. MotionLab에서 원본을 미리 볼 수 있는 것과는 다르다.

`Fast`, `Slow`, `Additive`는 각 공격의 변형 파일이다. 파일 하나가 반드시 새로운 패턴 하나를 뜻하지는 않는다. 특히 Additive는 기본 자세에 더하는 보정용이므로 독립 공격처럼 바로 연결하지 않는다. 현재 기본 공격은 보정한 Slow 계열 구간을 사용하며, 모든 원본 변형을 독립 카드로 사용하지 않는다.

기획적으로 먼저 검토할 모션은 다음 세 가지다.

1. **점프 어퍼컷:** 원래 원했던 ‘왼손 → 오른손 → 점프 어퍼컷’ 경험과 현재 훅 마무리의 차이를 결정한다.
2. **이동 시작·멈춤과 Circle:** 보스의 접근·정지·옆 이동을 발의 동작으로 보여준다.
3. **사망:** 포트폴리오 영상에 전투가 끝났음을 보여준다.

모션 수를 늘리기 위해 전부 연결하는 것이 목적은 아니다. 기본 주먹과 다른 준비 신호, 피하는 방법, 반격 기회가 있는지 보고 역할을 정한다. 이번 요청에서는 7번 FX만 수정했으며 위 미사용 모션을 새 AI 패턴으로 연결하지 않았다.

참조 목록은 `Saved/VibeUE/crunch-unused-motion-references-20261005.json`에 저장했다. 에셋 레지스트리 참조는 캐시와 코드의 문자열 로딩을 모두 증명하지 못한다. 따라서 실제 공격 카드와 함께 해석하며, MotionLab의 원본 비교 목록은 `BossMotionLabDirector.cpp`도 읽어 구분했다. 이전 전체 연결 설명은 [애니메이션·AI 연결 점검](crunch_animation_ai_connection_audit_20261005.md)에 있다.
