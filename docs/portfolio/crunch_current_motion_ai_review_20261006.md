# Crunch 모션·판정·AI 현황과 새 공격 선택표

이 문서는 2026-10-06 에디터에 저장된 공격 카드와 실제 모션 연결을 읽어 정리한 검토표다.
이번 요청에서는 게임 설정을 수정하지 않았다. 아래의 ‘현재’와 ‘원하는 변경’을 구분한다.

## 먼저 구분할 내용

- **공격 시작 거리**는 공격을 시도해도 되는 조건이다. 그 거리 전체가 피해 범위인 것은 아니다.
- **실제 타격**은 손 주변의 판정이 플레이어와 겹쳤을 때 발생한다. 공격을 시작해도 안 닿으면 피해가 없다.
- MotionLab은 번호로 모션과 판정을 확인하는 곳이다. Utility의 선택과 GOAP의 위치 준비는 Arena에서 확인한다.
- 파일 이름의 Combo_01/02/03은 각각 한 타 동작이다. 이 동작을 연결해서 별도 2연타·3연타를 만들었다.
- 2번의 현재 데이터 이름은 ‘바디 펀치’지만, 새로 채택한 **지상 돌진 바디펀치**는 아직 별도 모션으로 구현하지 않았다.

## 현재 공격과 모션

거리 단위는 캐릭터 중심 사이 cm다. 피해는 가드·무적 등을 처리하기 전 기본값이다.
점수는 기본 점수이며 실제 선택 확률이 아니다. 재사용 대기 0초도 현재 공격·후딜을 끝내야 새로 공격할 수 있다.

접근은 별도의 공격 모션이 아니라 이동 행동이다. 기본 점수 70이며 225cm 이상에서 후보가 된다.
원래 구상한 `01 → 02 → Ability_Uppercut`과 현재 `01 → 02 → Ability_Hook`은 다르다.
현재 3연타의 마지막은 오른손 훅이다. 점프 어퍼컷 패턴을 만들려면 별도 연결이 필요하다.

| 전진 | Jog_Fwd |

현재 활성 `BS_Boss_8Way`는 대기와 네 방향의 **5개 기본 샘플**을 사용한다.
방향 입력은 대각도 처리하지만, 대각·Circle 전용 클립을 각각 배치한 구성은 아니다.
보유한 Circle 클립들은 별도 연결 후보로 검토할 수 있다.

## 현재 전진과 원하는 거리 구분

| 항목 | 실제 현재 구현 | 사용자가 새로 정한 방향 |
|---|---|---|
| 기본 주먹 | 300cm 미만은 기존 발 곡선의 작은 이동(약 66/87cm 요청), 300~400cm는 145cm 요청 | 340cm까지는 기본 제자리 공격으로 대응 |
| 새 중거리 공격 | 아직 새 모션·행동 카드 없음 | 350~460cm에 지상 바디펀치 등 별도 공격 |
| 휩쓸기 | 285cm를 넘으면 시작 거부, 따라서 중거리 Utility 후보도 제외 | 중거리까지 사용 가능한지 손 궤적을 보고 범위 결정 |
| 연타 후속 타 | 새 전진을 한 번 계산, 최대 180cm 요청 | 뒤로 회피하는 플레이어에게 다음 잽으로 압박 유지 |
| 슈퍼맨 | 500~1000cm에서 접근과 함께 후보 | 원거리 특수 공격 역할 유지 |

145/180cm는 **전진 요청 상한**이다. 벽과 플레이어 몸에 막히면 실제 이동은 줄어든다.
340/350/460cm의 새 경계는 이번 검토 중 아직 적용하지 않았다.
로그의 약 393cm 휩쓸기 요청은 손이 닿기 전에 시작 거리(최대 285cm)에서 거부됐다.

## 판정은 어떻게 작동하나

| 확인할 것 | 현재 방식 | 기획자가 결정할 것 |
|---|---|---|
| 공격 시도 허용 | 해당 기술의 시작 거리·방향·재사용 대기를 먼저 확인 | 어느 거리에서 어떤 기술을 허용할지 |
| 주먹의 실제 명중 | 손 주변의 여러 검사점과 그 이동 경로로 접촉 검사 | 어느 손, 어느 구간, 어느 정도 여유를 줄지 |
| 양손 휩쓸기 | 두 손을 검사하되 같은 타격으로 중복 피해 방지 | 옆으로 넓게 압박할 범위와 판정 지속 시간 |
| 연타 | 각각 별개의 손·시간·피해로 판정 | 각 타의 간격, 전진, 계속할 조건 |
| 점프 내려찍기 | 착지 지점 주변 범위 피해 | 바닥 표시, 목표 확정 시점, 착지 범위 |
| 플레이어 회피 | 손 접촉과 현재 무적 상태를 함께 처리 | 허용할 타이밍과 기술별 회피 대응 |
| 플레이어가 보스 몸을 때림 | 보스 모델의 부위별 물리 형상을 대상으로 접촉 확인 | 부위별 피격 느낌과 누락된 영역 |
| 서로 몸으로 막힘 | 이동용 캐릭터 캡슐을 사용 | 이동 중 겹침, 너무 가까워지는 상황 |

현재 손 공격은 팔꿈치·어깨 공격을 자동으로 포함하는 시스템이 아니다. 그런 공격을 추가하면
그 부위에 맞는 별도 검사 위치가 필요하다. 모든 모델 폴리곤이 모든 역할의 충돌을 담당하는 것도 아니다.
불꽃·붉은 아우라가 보여도 그 자체가 피해 영역은 아니다.
휩쓸기는 아직 ‘옆 회피는 반드시 맞고 뒤 회피만 성공’이라는 방향 강제 규칙을 넣지 않았다.

## 지금 시간표에서 특히 검토할 부분

아래는 저장된 시간표를 공격 시작 시점 기준 초로 환산한 값이다.
실제 플레이의 첫 접촉 프레임 실측은 아니다. 손 판정 시간과 화면의 공격 상태 표시 시간은 별도다.
마지막 창 뒤 남는 시간은 기본 완주 시간표 기준이며 중단·특수 분기·피격 반응은 포함하지 않는다.

| 2 | 0.52~0.68초 | 3.22초 | 약 2.53초 |
| 3 | 0.60~0.72초 | 2.40초 | 약 1.68초 |

| 6 | 1.18~1.55초 | 2.68초 | 약 1.13초 |

따라서 지금 잽잽훅은 **첫 잽에서 둘째 잽까지 약 2.42초**다. 후속 전진을 넣었어도
이 간격이 길면 ‘잽잽’의 빠른 연결감이 부족할 수 있다. 기본 주먹도 손 판정이 끝난 뒤
다음 선택까지 남는 시간이 길다. 처음 이야기한 약 0.6초 반격 여유와는 차이가 크다.
새 모션을 늘리기 전에 이 시간표를 다시 정하는 것이 필요하다.

## 어퍼컷 연출 정정

| 현재 | 사용자가 원하는 수정 |
|---|---|
| 시작 전에 0.4초 준비 시간을 넣고 손 불꽃·방출 효과를 사용 | **Crunch 몸 전체에서 연기가 마구 피어오르고, 이어서 어퍼컷을 터뜨림** |

전신 연기는 아직 적용하지 않았다. 현재 코드의 손 충전 효과는 Windup 상태를 검사하는데,
별도의 0.4초 준비 상태는 Telegraph다. 따라서 준비 시간 전체에 충전 효과가 보이도록
연결됐다고 볼 수 없다. 새 연기 연출은 이 상태 연결도 함께 고쳐야 한다.
연기의 색·양·지속 시간, 모으는 자세, 주먹을 낼 때 연기가 어떻게 퍼질지 사용자가 결정한다.

## HFSM / Utility / GOAP의 현재 역할

| 담당 | 쉬운 설명 | 현재 하는 일 |
|---|---|---|
| HFSM | 지금 무엇을 해도 되는지 관리 | 등장 → 관찰 → 선택 대기 → 필요하면 위치 준비 → 신호 → 공격 준비 → 타격 → 연타 사이 연결 또는 후딜 → 다시 대기. 죽으면 전투 종료 |
| Utility | 지금 어떤 행동이 어울리는지 비교 | 거리·방향·재사용 대기·회피/가드 기록·최근 쓴 공격을 반영한 뒤 점수에 비례해 추첨 |
| GOAP | 선택한 공격을 할 자리를 준비 | 거리와 방향이 맞으면 바로 공격. 안 맞으면 짧게 진입·거리 확보·몸 돌리기·막힌 길의 측면 자리 준비 |

세 기능은 같은 일을 세 번 하는 것이 아니다.
**Utility가 고른 공격을 GOAP가 준비하는 동안 유지하고, HFSM이 공격의 실행과 종료 규칙을 지킨다.**

## Utility의 현재 기준

| 상황 | 현재 처리 | 검토할 점 |
|---|---|---|
| 시작 거리 밖 | 후보 점수 0, 또는 일반 주먹·2연타의 제한된 위치 준비 후보 | 휩쓸기 시작 상한이 작아 중거리 후보에서 빠짐 |
| 같은 공격을 바로 다시 선택 | 반복 계수로 감점 | 반복 감점은 확정 번갈아 쓰기가 아님 |
| 최근 사용한 기술 | 약 12초에 걸쳐 선호도가 회복 | 기술별 출현 빈도는 실제 플레이로 확인 |
| 일반 주먹 묶음을 사용 | 왼손·오른손·연타에 묶음 감점, 어퍼컷은 별도 | 주먹끼리만 계속 교대하는 것을 줄이려는 장치 |
| 최근 회피 0~1회 | 3연타 관찰 점수 0 | 시작부터 3연타를 보여줄지 결정 필요 |
| 최근 회피 2회 | 3연타 관찰 점수 20 | 낮은 가능성으로 후보 |
| 최근 회피 3회 이상 | 3연타 관찰 점수 40 | 기존 재사용 대기·거리·반복 감점은 계속 적용 |
| 최근 가드 누적 2초 이상 | 가드 깨기 후보 | 가드 압박에 따른 추가 보정도 있음 |
| 500cm 미만에서 공격 후보가 있음 | 별도 ‘접근’ 후보 억제 | 불필요한 접근 반복 방지 |
| 500~1000cm | 접근 70, 슈퍼맨 20을 기본으로 비교 | 멀다고 슈퍼맨 확정 아님 |
| 2페이즈·1000cm 이상 | 예정된 첫 점프는 우선 검사, 이후 점프는 후보 비교 | 첫 점프 우선 분기는 일반 추첨과 구분 |

가드·회피는 최근 약 6초 기록을 사용한다. 위 표의 관찰 점수도 최종 확률은 아니다.
예를 들어 접근 70점과 슈퍼맨 20점만 남으면 슈퍼맨은 약 22%다. 재사용 대기나 경로가 막히면 달라진다.

## GOAP의 현재 기준

| 상황 | 행동 | 제한 |
|---|---|---|
| 이미 해당 기술의 시작 거리 안이고 앞을 봄 | 준비 동작으로 바로 진입 | 불필요한 접근 없음 |
| 시작 거리보다 멂 | 그 기술을 시작할 거리까지 짧게 이동 | 선택한 공격 유지, 최대 2초 |
| 해당 기술의 최소 거리보다 가까움 | 약간 물러나 공간 확보 | 밀착 공격 후보는 최소 거리 안이면 바로 사용 |
| 방향이 안 맞음 | 몸을 돌려 준비 | 순간 180도 전환을 하지 않음 |
| 정면 진입이 막힘 | 실제로 이동할 수 있는 좌우 자리 검사 | 측면 진입은 해당 준비 중 한 번 |
| 일반 주먹·2연타 후 다음 공격 준비 | 조건에 따라 짧은 측면 자리 이동 | 25% 시험값, 4초 재사용 제한 |
| 짧은 시간에 진입 2회 실패 | 0.65초 관찰 뒤 다시 선택 | 계속 쫓아오기만 하는 반복을 끊음 |

GOAP가 아직 긴 복싱 전략을 만드는 것은 아니다. 현재는 **고른 공격을 할 위치를 준비하는 작은 계획**이다.
연타 도중의 180cm 전진은 이 GOAP 이동과 별개로, 공격 내부에 붙인 디딤이다.
다음 타의 방향 준비가 타격 사이 상태 전환 뒤에도 유지되는지는 별도 확인이 필요하다.

## 새 공격 컨셉 선택표

아래는 **제안**이다. A의 컨셉은 사용자가 좋다고 했지만 새 모션·판정·수치는 아직 없다.

| 코드 | 공격 컨셉 | 보고 느낄 동작 | 전투 역할 | 모션 준비 |
|---|---|---|---|---|
| A | 지상 돌진 바디펀치 | 몸을 낮추고 뒤발로 밀어 짧게 파고들며 몸통 펀치, 앞발로 제동 | 350~460cm 전용 압박. 공중 슈퍼맨과 구분 | 전진·제동 자세가 있는 새 동작 시안 필요 |

우선 추천은 **A + B**다. 새 중거리 역할 하나와 보유 모션을 활용한 연타 하나를 비교할 수 있다.
그 다음 C 또는 D를 선택하면 이동 리듬이나 엇박을 보강한다. 모두 구현할 필요는 없다.
처음부터 완성된 전신 애니메이션 품질을 가정하지 않고, 하나의 시안을 랩에서 보고 발 접지·체중 이동을 수정한다.
