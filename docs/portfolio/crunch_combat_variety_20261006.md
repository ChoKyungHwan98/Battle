# Crunch: 실험실에서 확인한 디딤을 실제 AI 선택에 연결

후속 요청: [플레이어 손맛·충전 어퍼컷·연타 전진·몸 아우라·중거리 모션 제안](crunch_combat_feel_and_midrange_proposal_20261006.md).
사용자가 새로 정한 350~460cm 중거리 모션은 후속 문서의 제안 단계이며 아직 거리 설정을 변경하지 않았다.

## 원했던 경험과 발견한 차이

느리지만 연속 공격을 시도하는 기계 복서다. 붙어 있으면 주먹만 반복하는 대신
어퍼컷과 양손 휩쓸기로 리듬을 바꾼다. 조금 떨어져 있으면 달려가서 멈추는 행동만
반복하지 않고, 한 발 내디디며 주먹을 낸다. 멀리 떨어진 상황에서도 돌진만 강제하지 않는다.

사용자는 MotionLab의 한 발 전진을 보고 “괜찮네”라고 했으며 실전 AI에 연결하길 요청했다.
직전 로그에서 랩은 강제 한 발 모드(2)를 사용했다. 실전 오른손은 시작 거리 약 312cm에서
전진 요청 약 87cm였다. 랩의 145cm 요청과 달랐다. 실전의 근접 판단 한 번에서는
어퍼컷 15.86점, 휩쓸기 22점이 남아 있었으나, 다른 중거리 판단에서는 사거리 때문에
둘 다 0점이었다. 이 짧은 로그만으로 전체 출현 빈도를 확정하지 않는다.

## 플레이어에게 보일 거리별 행동

| 상황 | 선택할 수 있는 행동 | 위치 준비 |
|---|---|---|
| 약 175cm 밀착 | 왼손, 오른손, 왼손 어퍼컷, 양손 휩쓸기, 2연타 | 이미 거리와 방향이 맞으면 바로 준비 동작 |
| 회피가 잦은 근접 상황 | 기존 3연타의 선택 가능성 증가 | 해당 연타의 시작 범위 확인 |
| 가드를 유지하는 근접 상황 | 빨간 신호를 주는 가드 깨기의 가능성 증가 | 기존 가드 관찰 조건과 쿨다운 확인 |
| 300~400cm | 한 발 디디는 왼손 또는 오른손 | 기본 주먹은 먼저 달려들 필요 없이 시작 가능 |
| 400cm 초과~500cm 미만 | 선택한 주먹을 시작할 자리까지 짧게 진입 | 선택한 공격을 유지하고 준비, 진입 제한은 2초 |
| 500~1000cm | 슈퍼맨 펀치 또는 달려서 접근 | 돌진 경로와 쿨다운 검사 |
| 1000cm 이상, 2페이즈 | 점프 공격 또는 접근 | 점프는 기존 1000~5000cm 조건 |

어퍼컷은 단타 `Ability_Combo_03`이며 점프하는 `Ability_Uppercut`과 구분한다.
원거리에서 어퍼컷·휩쓸기가 바로 나가지 않는 것은 손이 닿는 범위가 다르기 때문이다.
이번에는 공격 판정을 늘려서 멀리 있는 플레이어를 맞히게 만들지 않았다.

## 단조로움을 줄인 방법

| 행동 | 이전 기본 점수 | 이번 기본 점수 |
|---|---:|---:|
| 왼손 | 35 | 28 |
| 오른손 | 35 | 28 |
| 어퍼컷 | 20 | 30 |
| 양손 휩쓸기 | 22 | 30 |
| 슈퍼맨 | 12 | 20 |
| 접근 | 88 | 70 |

점수는 확률 그 자체가 아니다. 거리, 방향, 쿨다운, 최근 사용, 플레이어 행동 조건을
통과한 후보들의 최종 점수를 모아서 추첨한다. 높은 점수 하나를 항상 고르지 않는다.
예를 들어 슈퍼맨 20점과 접근 70점만 남으면 슈퍼맨은 약 22%, 접근은 약 78%다.
실전에서는 다른 조건과 감점 때문에 이 비율도 달라진다.

이전에는 어퍼컷도 일반 주먹 묶음에 속해서 기본 주먹을 쓴 뒤 같이 감점됐다.
이제 일반 주먹 묶음은 왼손·오른손·기존 연타로 한정했다. **기본 주먹을 썼다는 이유로
독립 어퍼컷까지 같이 억제하지 않는다.** 어퍼컷 자체를 최근 썼다면 기존 개별 반복
감점은 그대로 적용한다. 휩쓸기의 4초 쿨다운, 3연타의 회피 조건, 가드 깨기 조건도 유지한다.

## 디딤 연결과 세 AI의 역할

300~400cm 일반 주먹은 랩에서 확인한 **145cm 한 발 전진 요청**을 사용한다.
300cm 미만에서는 원래 발 곡선의 요청량(왼손 약 66cm, 오른손 약 87cm)을 사용한다.
벽이나 플레이어의 몸에 막히면 실제 이동은 더 짧아진다. 요청한 145cm가 항상 실제
이동 145cm라는 뜻은 아니다. 전진량은 공격 시작 시 한 번 저장하고, 공격 중 계속
플레이어를 쫓아 늘리지 않는다. 발 이동의 시간 곡선과 주먹 재생속도는 유지한다.

기획자가 설명할 때는 다음처럼 말하면 된다.

> Utility는 지금 쓸 공격을 고른다. GOAP는 그 공격을 할 자리를 준비한다.
> HFSM은 준비·공격·후딜의 약속을 지키며 실행한다.

예를 들어 350cm에서 오른손을 고르면, 오른손 시작 범위(400cm 안)에 이미 있으므로
불필요하게 먼저 달려가지 않는다. 바로 준비한 뒤 발을 내디디며 친다. 반대로 공격할
방향이 안 맞거나 시작 범위 밖이면, GOAP가 선택을 유지한 채 몸을 돌리거나 짧게 진입한다.
준비 중 매번 다른 공격을 뽑지 않는다. 공격을 끝내고 후딜까지 마친 다음 새로 판단한다.

이번에 새 GOAP 목표를 추가한 것은 아니다. 기존 선택 유지·위치 준비 실행 경로에
10개 공유 행동 카드가 연결됐는지 다시 확인하고, 전진 주먹과 후보 점수를 맞춘 변경이다.
Arena와 MotionLab은 같은 공격 카드를 사용한다. 랩의 기본/강제 전진 비교 기능은 유지한다.

## 확인 범위

변경 스크립트는 `Tools/ApplyCrunchCombatVariety.py`다. 카드, 몽타주 참조, 일반 주먹
묶음 조건, 점수 합산 뒤 추첨, 선택 유지 실행 연결을 저장 후 재조회한다.
빌드와 네이티브 경계 검사는 별도 보고서에 기록한다. 에이전트는 PIE를 시작하지 않는다.

다음 사용자 플레이에서 확인할 것은 밀착 어퍼컷·휩쓸기 출현, 300~400cm의 한 발 주먹,
500cm 이후 슈퍼맨과 접근의 혼합이다. 벽·뒤로 걷기·옆 이동까지 포함한 실제 명중감과
자연스러움은 새 플레이 로그와 화면 피드백으로 확인해야 한다.
