# Crunch 공격 FX와 MotionLab 확인 안내

## 의도

플레이어가 보스의 손 움직임과 타격 순간을 알아보기 쉽게 만든다. 기본 주먹, 양손 휩쓸기, 돌진, 착지의 차이를 시각적으로 보여준다. 효과가 크다고 공격 범위가 넓어지는 것은 아니다. 피해는 기존 손 접촉 판정과 착지 범위 판정이 결정한다.

원본 Crunch 불꽃을 그대로 붙여 처음 확인했을 때는 불꽃이 보스의 몸을 가렸다. 처음에는 손 효과를 원본의 0.18 크기, 접촉 효과를 0.30 크기로 낮췄다. 이후 사용자가 “4번 휩쓸기는 괜찮지만 전반적으로 약하고 기본 주먹 효과가 잘 안 보인다”고 평가했다. 따라서 휩쓸기는 유지하고, 기본 주먹은 크기를 키우고 더 일찍 켜서 불꽃이 보일 시간을 확보했다. 반복 확인에서 발견한 잔여 불꽃 문제는 계속 방지한다. 손 효과는 지정 구간 종료 또는 모션 중단 시 즉시 제거한다.

## 가시성 조정값

아래 크기는 원본 대비 길이 배율이며, 피해량이나 공격 범위 배율이 아니다.

| 공격 | 손 효과 크기 | 접촉 효과 크기 | 조정 의도 |
|---|---:|---:|---|
| 왼손·오른손 기본 공격 | 0.75 | 1.25 | 더 크게, 타격 후까지 불꽃 유지 |
| 단독 어퍼컷 (3번) | 0.75 | 1.25 | 없던 왼손 불꽃 추가 |
| 연결 공격 | 기본 두 타 0.75 / 마지막 훅 0.55 | 1.25 | 타격 사이를 줄이고 각 손의 불꽃도 오래 유지 |
| 양손 휩쓸기 | 양손 각각 0.40 | 0.55 | 추가 요청에 따라 양손 효과 확대·연장 |
| 가드 깨기 | 0.75 | 1.10 | 오른손 불꽃과 접촉 충격 확대 |
| 슈퍼맨 펀치 | 기본 불꽃 1.10 + 강화 불꽃 0.85 + 양손 분사 각각 0.75 | 1.15 | 불꽃과 추진 분사를 겹쳐 돌진 강조, 지면 흔적 크기 1.60 |
| 점프 내려찍기 | 없음 | 착지 충격 0.90 | 기존 지면 충격파와 밝은 Crunch 충격 입자를 함께 재생 |

현재 기본 왼손 불꽃은 몽타주 0.107~0.950초, 오른손은 0.093~0.950초에 켠다. 단독 어퍼컷은 0.010~0.820초, 양손 휩쓸기는 0.400~1.550초, 가드 깨기는 0.140~1.060초, 돌진 주먹은 0.500~3.350초다. 돌진은 접촉 시 2.520초의 회복 구간으로 넘어가므로, 그 구간에서도 불꽃이 이어지도록 종료를 늦췄다. 불꽃이 보이는 구간 전체에 피해가 있는 것은 아니다.

### 추가 요청: 더 큰 불꽃과 더 빠른 5번

사용자가 “너무 일찍 꺼진다. 더 크게. 확인은 내가 한다”고 요청했다. 위 표는 이 추가 수정까지 반영한 **현재 설정**이다. 이번 수정에는 PIE 실행·화면 캡처·플레이테스트를 수행하지 않았으며, 저장과 Blueprint 컴파일까지만 진행했다. 아래의 통과 기록은 이 추가 수정 **전** 버전의 결과다.

5번은 공격 원본 구간을 기존보다 1.15배 빠르게 재생한다. 첫 타 뒤의 회복 구간은 1.6배에서 2.4배, 타격 사이 자세 연결은 1배에서 1.4배로 바꿨다. 자세 연결을 삭제하지 않고 빨리 통과시켜 다음 주먹을 더 빨리 낸다. 몽타주 길이는 약 5.447초에서 4.478초로 줄었다. 액션 시작 기준 예정 타격 시각은 약 `0.762 / 3.917 / 6.161초`에서 `0.695 / 3.142 / 5.045초`로 옮겼다. 손 판정 알림, 판정 종료 시각, 불꽃도 같은 시간 변환으로 맞췄다.

공격 뒤의 반격 시간을 줄이지 않도록 전체 행동 길이는 8.950초에서 약 7.834초로 옮겼다. `ActiveSeconds=0.95`와 마지막 공격 상태 뒤 약 1.839초의 회복 시간은 유지했다. 실제 체감과 현재 설정에서의 반격 성공 여부는 사용자가 확인한다.

### 7번 추가 강화

사용자가 슈퍼맨 펀치의 파티클이 더 많이 보여야 한다고 요청했다. 기존 주먹 불꽃은 0.85에서 1.10으로, 지면 흔적은 1.20에서 1.60으로 키웠다. `P_Crunch_Cross_AmpedFLames`를 왼손에 0.30~3.35초 동안 연결했고, `P_Crunch_Cross_Jets`를 양손에 각각 0.25~1.50초 동안 연결했다. 지면 흔적의 종료는 1.80초로 늦췄다. 추진 분사, 강화 불꽃, 기본 주먹 불꽃, 지면 흔적을 함께 쓰는 구성이다. 이번 추가 연결의 실제 가시성과 크기는 사용자가 MotionLab 7번으로 확인한다. 새 레이어의 입자 수나 화면 결과를 확인했다는 뜻은 아니다. 피해·이동·공격 타이밍은 이번 추가 강화에서 변경하지 않았다.

돌진용 `P_Crunch_Fist_Fire_Cross`는 확인한 돌진 프레임에서 컴포넌트가 활성 상태여도 생성된 입자가 0개였다. 크기를 키우는 것만으로 해결되지 않아, 기본 주먹에서 보이는 것을 확인한 `P_Crunch_Fist_Fire_UpperCut`으로 연결했다. 교체 후 같은 프레임에서 162개 입자와 화면의 불꽃을 확인했다. 착지는 약하게 보이던 `P_LevelStart_Fist_Slam` 대신 `P_Crunch_Uppercut_Impact`를 같은 착지 실행 지점에 연결했다. 효과 원본 자체는 수정하지 않았다.

## MotionLab에서 확인할 것

`Lvl_BossMotionLab`을 열고 Play 한다. **숫자 키는 실제 전투 공격**이다.

| 키 | 공격 | 이번에 연결한 효과 |
|---|---|---|
| 1 | 왼손 휘두르기 | 왼손의 짧은 불꽃 + 접촉 지점의 충격 |
| 2 | 오른손 휘두르기 | 오른손의 짧은 불꽃 + 접촉 지점의 충격 |
| 4 | 양손 휩쓸기 | 양손 불꽃 + 휩쓸기 전용 접촉 효과 |
| 5 | 왼손 → 오른손 → 훅 연결 공격 | 각 타격 손에 순서대로 불꽃 + 실제 접촉 효과 |
| 6 | 가드 깨기 | 기존 빨간 경고 + 오른손 불꽃 + 리버블로 접촉 효과 |
| 7 | 슈퍼맨 펀치 | 돌진 중 지면 흔적 + 왼손 효과 + 돌진 전용 접촉 효과 |
| 9 | 점프 내려찍기 | 기존 착지 범위·충격파 + 지면의 착지 입자 |

3번은 단독 어퍼컷이며 이번 추가 수정에서 왼손 불꽃을 연결했다. 자율 전투에서의 비활성 설정은 유지한다. 8번은 접근 행동이다.

`R`은 위치 초기화, `Z/X/V/B`는 거리 변경, `H`는 판정 표시, `Tab`은 조작 안내다. 우선 X 거리에서 1/2/4/5/6, B 거리에서 7/9를 확인한다. 멀리서 1번을 실행하면 손의 효과는 나오지만 플레이어 접촉 효과는 나오지 않아야 한다.

확인 기준은 “멋진가”와 함께 **“효과가 손에 붙어 있는가, 동작을 가리지 않는가, 실제로 닿을 때 접촉 효과가 나오는가, 후딜에도 계속 위험해 보이지 않는가”**다.

## Arena에도 반영되는 범위

숫자 키로 실행하는 MotionLab 공격과 `Lvl_Arena_01`의 AI 공격은 동일한 `BP_Boss_Crunch`, 공격 카드, 공격 몽타주를 쓴다. 이번 FX와 공유 몽타주·공격 카드에 저장된 재생 속도 및 타격 시간은 두 맵에 적용된다. 맵마다 따로 복사해서 맞추지 않는다.

다만 **O와 T/Y/U/I는 원본 모션 비교용**이다. O는 선택한 원본 애니메이션을 재생하며, T/Y/U/I는 원본 준비·공격·회복 모션을 연결해 보여준다. 이 미리보기만 본 뒤에는 Arena의 실제 타이밍을 확인했다고 말할 수 없다. 최종 전투 타이밍과 FX는 숫자 키로 판단한다. 시험 중 시간 정지나 거리 변경도 전투 설정을 저장하는 기능이 아니다.

MotionLab에서는 자율 AI를 억제하고 선택한 공격 하나를 시험한다. Arena에서는 Utility 선택과 후속 행동이 이어지므로 공격 **선택과 연결 빈도**는 다르게 보일 수 있다. 같은 것은 각 공격의 공통 실행 설정이다.

## 기획자가 설명할 문장

> 손의 불꽃은 ‘어떤 손으로 공격을 준비하고 휘두르는지’를 보여주고, 접촉 효과는 ‘실제로 닿았는지’를 알려줍니다. 처음에는 효과를 줄였지만 기본 주먹이 잘 안 보여서, 휩쓸기는 유지하고 다른 공격은 크기와 시작 시점을 다시 조정했습니다. 효과가 커져도 피해 범위는 그대로입니다. 실험실과 전투 맵은 같은 공격 설정을 씁니다.

## 구현 위치

- 공유 공격 몽타주: `/Game/BossArena/Boss/Animations/`의 실제 사용 중인 6개 몽타주. `BossFX` 시간표에 효과 시작과 종료를 기록했다.
- 손 FX 크기 조절: `/Game/BossArena/Boss/FX/ANS_BossScaledParticle`. 원래 시간형 파티클 알림의 시작·종료 처리를 유지하고, 해당 손에 붙은 효과의 크기를 조정한다. 공유 알림 객체에 실행 중 파티클 참조를 저장하지 않는다.
- 접촉 FX: `BP_Boss_Crunch.ResolvePhysicalContact → PlayContactFX`. 기존 무적 검사·벽 검사·타격 중복 방지를 통과한 손 접촉에 붙였다. 회피 무적을 통과하지 못하면 접촉 효과도 발생하지 않는다.
- 착지 FX: `BP_Boss_Crunch.ResolveSlamImpact`. 기존 충격파와 같은 착지 위치, 바닥 위 8cm에서 재생한다.
- 효과 원본: ParagonCrunch의 기존 ParticleSystem. 원본 에셋은 수정하지 않았다.
- 추가 수정에서 5번의 모션 구간 속도와 이에 연결된 타격·효과 시간을 함께 바꿨다. 다른 공격의 타격 시간, 피해량, Utility 점수, GOAP 계획은 유지했다.
- 확인 스크립트: `tools/TestBossAttackFX.py`. 실전 숫자 키 입력, 접촉/빗나감 분리, 공격 후 효과 종료를 기록한다.

시간표의 숫자는 몽타주 내부의 초다. 예를 들어 0.75배속 공격의 0.18초 효과 구간은 실제 시간으로 0.24초 동안 재생된다. 전투 시작부터의 초와 혼동하지 않는다.
