# Crunch 전진형 왼손: Control Rig 제작 및 QA

## 이번에 만드는 경험

왼발이 앞인 준비 자세에서 오른발을 앞으로 옮기고, 바닥을 짚으며 몸을 실어 왼손을 휘두른다.
기존 왼손의 공격 느낌을 출발점으로 삼는다. 전진형의 시작 거리 550cm 접촉은 목표이며,
몸의 이동량 205cm를 입력했다는 이유만으로 도달이나 모션 품질을 합격으로 판단하지 않는다.

## 제작 경로

현재 Unreal MCP → UE5.8 Control Rig / Sequencer → AnimSequence Bake → Montage / Notify → MotionLab.
Mixamo, 외부 모캡, 다른 캐릭터의 모션은 사용하지 않는다. 달리기 하체를 붙이는 방식도 사용하지 않는다.
원본 Crunch 시퀀스와 제자리 공격은 보존한다.

| 자산 | 역할 |
|---|---|
| `/Game/BossArena/Boss/Authoring/CR_Crunch_Attack` | 원본 자세용 FK, 발 목표, 무릎 방향, 다리 IK, Backwards Solve |
| `/Game/BossArena/Boss/Authoring/LS_Crunch_RightStep_LeftSwing` | 수정 가능한 공격 편집 원본 |
| `/Game/BossArena/Boss/Authoring/AS_Crunch_RightStep_LeftSwing` | Sequence에서 출력한 게임용 애니메이션 |
| `/Game/BossArena/Boss/Authoring/AM_Crunch_RightStep_LeftSwing` | 타격/FX Notify를 배치하는 Montage |

## 사용자가 확인할 것

### 2026-10-07 발걸음 축소 v2

사용자 영상에서 공격 뒤 양발을 다시 옮기는 동작이 과하게 보였다.
오른발의 주 디딤은 유지하고, 뒷발 보정은 이동 97→60cm(애니메이션 공간), 들기 11→2cm로 줄였다.
후딜에 넣었던 왼발 재전진과 오른발 재배치를 제거했다. 공격 후에는 디딘 자세를 유지한다.
기존 Root 이동 키, 펀치 키, 타격/FX Notify 시간은 유지했다.

Bake한 제작 프레임에서 발 목표 오차는 최대 약 0.000124cm, 후딜 발 위치 변화는 약 0.000107cm 이하였다.
이는 애니메이션의 발 목표 재현 검사이며 자연스러움의 합격 판정은 아니다.
테스트에서는 후딜에 발을 계속 들지 않는지, 뒷발 보정이 과하지 않은지,
마지막 대기 자세로 돌아가는 연결이 튀지 않는지 확인한다.

`Lvl_BossMotionLab`에서 L로 비교 방식을 바꿔 **오른발 디딤 → 왼손 · 1키 전용**을 선택하고 1을 누른다.
기본 제자리 모드의 1과 비교한다. H는 판정 표시, J는 거리 측정, R은 실험 배치 초기화다.

1. 오른발을 들고 옮기는 동작이 눈에 보이는가?
2. 오른발이 착지한 뒤 몸이 실리고 왼손이 나가는가?
3. 지지하는 왼발이 바닥 위를 미끄러지지 않는가?
4. 오른발이 착지한 다음 왼발이 풀리는가? 두 발이 동시에 미끄러지지 않는가?
5. 무릎이나 발목이 갑자기 돌아가지 않는가?
6. 기존 대기 자세로 돌아갈 때 튀거나 발이 끌리지 않는가?
7. 500cm와 550cm에서 실제 주먹이 닿는가? 보이지 않는 넓은 판정으로 대신 맞추지 않는가?

정상 속도 정면·측면에서 먼저 판단한다. 느린 재생은 문제가 발생한 구간을 찾는 데 사용한다.
피드백은 “착지 전 몸이 먼저 이동한다”, “오른발 착지에서 무릎이 튄다”처럼 구간과 현상을 알려주면 된다.

## 검증 범위

원본의 기본 FK 및 Crunch 전용 리그 왕복 Bake는 각각 비교 시점의 위치 차이 약 0.008cm 미만,
회전 차이 약 0.163도 이내였다. 이는 원본을 편집 경로로 옮기는 기능 검사다.
새 모션의 자연스러움이나 550cm 실제 타격이 검증됐다는 의미는 아니다.

새 모션의 기능 검사에서는 신규 Montage 재생과 약 204.91cm의 실제 캐릭터 전진을 확인했다.
**550cm에 멈춰 있는 플레이어에게는 피해가 발생하지 않았다. 550cm 도달 목표는 아직 미달이다.**
기능 검사의 통과 항목은 Montage 재생과 전진이며, 타격 거리 합격이 아니다.
이 시험의 기록은 `Saved/VibeUE/Scenarios/20261006T193542Z-EA21902C.json`이다.

제작 프레임의 발 목표 오차는 최대 약 0.00015cm였다. 이는 IK가 목표 위치를 재현하는지 검사한 값이다.
게임의 바닥 접촉, 무게감, 시작/끝 연결이 자연스럽다는 판단은 별도로 QA해야 한다.

이번 결과는 MotionLab 비교용 초안이다. 사용자의 동작 품질 QA 후 Arena의 Utility/GOAP에 확대한다.
