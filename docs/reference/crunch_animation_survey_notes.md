# 크런치 애니메이션 전수조사 기록

조사 종료. 사용자가 `똥깨`라고 말한 시점까지의 확인 사항을 정리했다. 검토 중인 연계는 [보스 모션 테스트 씬](boss_motion_lab.md)에서 비교할 수 있다.

## 기록 원칙

- 원본 시퀀스 이름을 그대로 적는다.
- 사용자가 직접 확인한 동작과 현재 프로젝트 연결 상태를 구분한다.
- 확정되지 않은 용도나 연계는 `검토`로 표시한다.
- 테스트 씬의 원본 시퀀스 미리보기와 실제 전투 패턴 연결을 구분한다.

## 현재까지 확인된 프로젝트 상태

| 시퀀스 | 현재 보스 연결 | 검토 메모 |
| --- | --- | --- |
| `Ability_Combo_01_Slow` / `Ability_Combo_01_Recovery` | 실제 1번 공격과 연계 첫 타격에 사용 | 1번 공격은 원본을 복제해 상체를 아래로 조정한 `Ability_Combo_01_Slow_Low` 뒤에 Recovery를 붙였다. 원본은 보존했다. |
| `Ability_Combo_02_Slow` / `Ability_Combo_02_Recovery` | 실제 2번 공격에 사용 | 빠른 왼손 타격과 Recovery를 이어 붙이고 판정 소켓도 왼손으로 맞췄다. |
| `Ability_DashingCross_Start` / `Ability_DashingCross` / `Ability_Dashing_Recovery_Hit` | 실제 슈퍼맨 펀치에 사용 | 원본 Start의 끝 자세가 본 공격 첫 자세와 크게 달라, 복제한 `Ability_DashingCross_Start_Bridged`의 마지막 6프레임을 연결 자세로 다듬었다. 시작 → 본 공격 → 적중 시 Hit Recovery, 실패 시 일반 Recovery로 분기한다. |

## 사용자 조사 기록

| 순서 | 사용자 확인·선호 | 현재 확인된 사실 | 상태 |
| --- | --- | --- | --- |
| 1 | `Slow` 모션이 있으므로 되도록 이를 사용하고 싶음. | 1번·2번·잽잽훅에 `Combo_01/02_Slow`를 적용했다. `Combo_03`은 아직 기존 공격이다. | 적용·검증. |
| 2 | 보스와 플레이어의 키 차이 때문에 보스가 허공에 주먹을 휘두르는 것처럼 보인다. 상체를 더 아래로 숙여야 할 수 있다. | 1번용 복제 시퀀스의 `spine_01`을 아래로 15도 조정했다. 230cm PIE에서 손의 전진 타격에 110 피해 1회, 회수 중 0회를 확인했다. | 1번 적용·검증. 다른 모션은 개별 확인 필요. |
| 3 | 콤보에는 가능한 Recovery 모션을 붙이고 싶다. | 1번은 Combo01 Recovery, 2번은 Combo02 Recovery를 붙였다. 잽잽훅은 첫 타격 뒤 Combo01 Recovery를 짧게 거쳐 두 번째 타격으로 이어진다. 원본 폴더에 Combo03/04 Recovery는 없다. | 가능한 구간 적용. |
| 4 | `Ability_Combo_03`은 너무 위로 찌르는 듯해 폐기할 수도 있다. | 170cm 실전 행동에서 피해 110은 들어갔지만 붉은 손 판정과 주먹이 플레이어 머리보다 높이 올라간 장면을 확인했다. `DA_Attack_Uppercut.bEnabled=false`로 자동 Utility 선택에서 제외했고, 테스트 씬의 3번 수동 재생은 남겼다. | 현재 근접 기본 패턴에서 제외. 낮은 대체 모션을 고른 뒤 재검토. |
| 5 | 현재 슈퍼맨 펀치 `Ability_DashingCross`가 밋밋해 보인다. 시작·회복을 넣고 대시 공격을 고도화하고 싶다. | 새 전투 몽타주에서 시작·본 공격·적중/실패 회복을 연결했다. 원본 Start 끝과 Cross 시작은 주요 8개 관절 평균 약 95cm 차이여서 복제본의 끝 6프레임을 보정했다. 보정 후 손·몸통 연결 위치 차이는 약 0.1cm 이하다. | 구성·접합 보정 적용. 실전 박력과 리듬은 플레이 감각 검토 대상. |
| 6 | `Ability_DashingCross_Start`를 슈퍼맨 펀치 본 공격 전에 재생하고 싶다. | 원본을 보존한 채 만든 `Ability_DashingCross_Start_Bridged`가 새 몽타주의 첫 구간이다. | 적용. |
| 7 | 플레이어가 슈퍼맨 펀치에 맞았다면 `Ability_Dashing_Recovery_Hit`을 재생하고 싶다. | 적중 시 Hit Recovery 섹션, 빗나가면 일반 Recovery 섹션으로 이동한다. PIE에서 적중 160 피해 1회와 두 분기의 재생 위치를 확인했다. | 적용·검증. |
| 8 | `Ability_Hook_Empowered`가 양손 휩쓸기 모션이다. | 현재 `DA_Attack_Sweep`이 이 시퀀스를 재생한다. | 사용자 확인. |
| 9 | 현재 공격 모션의 가짓수가 너무 적다. HFSM·Utility AI·GOAP에 실제 선택지가 얼마나 있는지 확인하고 싶다. | 행동 배열은 공격 8개와 접근 1개다. 높은 Combo03을 비활성화해 자동 공격 후보는 7개이며, 점프를 쓰지 않는 1페이즈에는 6개다. 현재 활성 공격 7개는 서로 다른 몽타주를 사용한다. GOAP 목표와 위치 행동은 공격 모션 수에 포함하지 않는다. | Slow/Recovery와 대시 분기로 기존 후보의 동작을 다듬었다. 신규 공격 종류를 늘리는 작업은 이번 범위 밖이다. |

### 용어 메모

- `Additive`: 기본 포즈나 애니메이션에 더할 자세 변화량. 현재 독립 공격 패턴으로 세지 않는다.
- `Slow`: 별도 이름을 가진 원본 시퀀스. `Ability_Combo_01`은 약 0.93초, `Ability_Combo_01_Slow`는 약 1.23초다. 01·02는 전투 몽타주에 적용해 판정과 연결을 시험했다. 03·04의 용도는 별도 검토가 필요하다.

## 테스트 씬에 반영한 검토 항목

- `T`/`Y`: Combo 01/02의 `Slow → Recovery`를 연속 재생한다.
- `U`/`I`: `DashingCross_Start → DashingCross → Recovery_Hit/Recovery`를 비교한다.
- `O`: 선택한 원본 시퀀스를 단독 재생한다. `Ability_Combo_03`과 `Ability_Hook_Empowered`도 직접 비교할 수 있다.
- `H`: 보스 손의 구체 판정과 플레이어 캡슐을 표시한다. 키 차이 때문에 보이는 타격과 실제 접촉이 어긋나는지 관찰한다.
- 미리보기는 여전히 원본 후보 비교용이다. 실제 전투 연결은 위 표의 변경 사항이 적용되었으며, 추가 고도화할 모션은 별도로 선택해야 한다.
