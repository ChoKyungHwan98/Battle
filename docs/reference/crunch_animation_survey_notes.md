# 크런치 애니메이션 전수조사 기록

조사 종료. 사용자가 `똥깨`라고 말한 시점까지의 확인 사항을 정리했다. 검토 중인 연계는 [보스 모션 테스트 씬](boss_motion_lab.md)에서 비교할 수 있다.

## 기록 원칙

- 원본 시퀀스 이름을 그대로 적는다.
- 사용자가 직접 확인한 동작과 현재 프로젝트 연결 상태를 구분한다.
- 확정되지 않은 용도나 연계는 `검토`로 표시한다.
- 테스트 씬의 원본 시퀀스 미리보기와 실제 전투 패턴 연결을 구분한다.

## 현재까지 확인된 프로젝트 상태

| 시퀀스 | 현재 보스 연결 | 검토 메모 |
| --- | --- | --- |
| `Ability_Combo_01_Recovery` | 실제 공격에는 미사용 | 테스트 씬 `T`에서 `Ability_Combo_01_Slow` 뒤에 이어 보며 연결감을 판단할 수 있다. |

## 사용자 조사 기록

| 순서 | 사용자 확인·선호 | 현재 확인된 사실 | 상태 |
| --- | --- | --- | --- |
| 1 | `Slow` 모션이 있으므로 되도록 이를 사용하고 싶음. | `Ability_Combo_01/02/03/04_Slow` 원본 시퀀스가 있다. 현재 보스 공격 몽타주는 일반 `Ability_Combo_01/02/03`을 사용한다. | 우선 검토 선호. 적용할 동작과 연결 방식은 조사 후 결정. |
| 2 | 보스와 플레이어의 키 차이 때문에 보스가 허공에 주먹을 휘두르는 것처럼 보인다. 상체를 더 아래로 숙여야 할 수 있다. | 현재 판정은 손 소켓을 따라가므로 자세를 바꾸면 보이는 손과 피해 판정을 함께 재검증해야 한다. | 시각 문제 및 조정 후보. |
| 3 | 콤보에는 가능한 Recovery 모션을 붙이고 싶다. | `Ability_Combo_01_Recovery`(약 1.47초), `Ability_Combo_02_Recovery`(약 1.80초)가 있다. `Ability_Combo_03_Recovery`, `04_Recovery`는 현재 원본 폴더에 없다. 현재 보스 콤보 몽타주에는 Recovery가 연결되지 않았다. | 어느 타격 뒤에 어떤 Recovery를 붙일지 조사 후 결정. |
| 4 | `Ability_Combo_03`은 너무 위로 찌르는 듯해 폐기할 수도 있다. | 현재 `DA_Attack_Uppercut`이 이 시퀀스를 단독 재생한다. | 폐기 후보. 아직 확정 아님. |
| 5 | 현재 슈퍼맨 펀치 `Ability_DashingCross`가 밋밋해 보인다. 시작·회복을 넣고 대시 공격을 고도화하고 싶다. | 현재 몽타주는 `Ability_DashingCross` 한 구간만 재생한다. | 패턴 개선 과제. |
| 6 | `Ability_DashingCross_Start`를 슈퍼맨 펀치 본 공격 전에 재생하고 싶다. | 원본 시퀀스가 있으며 길이는 약 0.33초다. 현재 보스 몽타주에는 미연결. | 원하는 순서: Start → DashingCross. |
| 7 | 플레이어가 슈퍼맨 펀치에 맞았다면 `Ability_Dashing_Recovery_Hit`을 재생하고 싶다. | 원본 시퀀스가 있으며 길이는 약 2.37초다. 현재 보스 몽타주에는 미연결. `Ability_Dashing_Recovery`(약 1.83초)도 별도로 있다. | 적중 시 회복 분기 제안. 빗나갔을 때의 분기는 미확정. |
| 8 | `Ability_Hook_Empowered`가 양손 휩쓸기 모션이다. | 현재 `DA_Attack_Sweep`이 이 시퀀스를 재생한다. | 사용자 확인. |
| 9 | 현재 공격 모션의 가짓수가 너무 적다. HFSM·Utility AI·GOAP에 실제 선택지가 얼마나 있는지 확인하고 싶다. | 현재 보스 행동 배열은 공격 8개와 접근 1개다. 바디 펀치·가드 브레이크가 `Ability_GutPunch` 몽타주를 공유해 공격 몽타주는 7종이다. 1페이즈에서 점프 내려찍기를 제외하면 공격 카드 7개·서로 다른 몽타주 6종이다. GOAP 목표 3개와 위치 행동 4개는 공격 모션 수를 늘리지 않는다. | 테스트 씬에서 실제 행동과 후보 모션을 구분해 검토. 신규 패턴은 아직 미선정. |

### 용어 메모

- `Additive`: 기본 포즈나 애니메이션에 더할 자세 변화량. 현재 독립 공격 패턴으로 세지 않는다.
- `Slow`: 별도 이름을 가진 원본 시퀀스. `Ability_Combo_01`은 약 0.93초, `Ability_Combo_01_Slow`는 약 1.23초다. 실제 동작 차이와 연계 가능성은 아직 시각적으로 확인하지 않았다.

## 테스트 씬에 반영한 검토 항목

- `T`/`Y`: Combo 01/02의 `Slow → Recovery`를 연속 재생한다.
- `U`/`I`: `DashingCross_Start → DashingCross → Recovery_Hit/Recovery`를 비교한다.
- `O`: 선택한 원본 시퀀스를 단독 재생한다. `Ability_Combo_03`과 `Ability_Hook_Empowered`도 직접 비교할 수 있다.
- `H`: 보스 손의 구체 판정과 플레이어 캡슐을 표시한다. 키 차이 때문에 보이는 타격과 실제 접촉이 어긋나는지 관찰한다.
- 위 미리보기는 기획 후보 비교용이며, 실제 보스 공격 몽타주와 판정 타이밍은 바꾸지 않았다.
