# 공격 판정 표시와 4타 조작감 조정

2026-09-29. DS3의 전투 구조를 참고하며, 수치와 판정 모양은 Battle의 검·방패 에셋과 Crunch에 맞춘다.

## 변경

| 항목 | 이전 | 현재 |

| 접촉 지점 | 큰 이펙트 중심 | 실제 HitResult.ImpactPoint에 녹색 표시 0.12초 |

각 클립의 타격 시작·종료 이벤트는 동작의 같은 시점에 유지한다. 재생 배율에 따라 실제 시간이 함께 빨라진다. 연계 이벤트는 타격 종료 이후에 배치했다. 공격 방향 고정, 루트 모션, 한 대상 한 타 1회, 입력 예약 규칙은 이어서 사용한다.

공격 판정은 현재 프레임만 표시해 선이 쌓이지 않게 했다. 녹색은 물리 접촉을 뜻하며, 무적·방어로 HP 피해가 없어도 접촉할 수 있다. `AttackDebugDrawMode=None`으로 범위 표시를 숨길 수 있다. 녹색 접촉 표시는 별도 디버그 그리기이며 UE 개발 실행용이다.

카메라 거리·피벗·수직 화각은 기존 DS3 참조 설정을 유지한다. 상시 충돌 캡슐과 큰 폭발 이펙트가 동작을 가리는 문제를 먼저 줄였다. 사용자의 세로 Shorts 캡처는 가로 게임 화면이 잘린 형태라 캐릭터의 화면 점유율을 직접 비교할 기준으로 삼지 않는다.

## 구현 위치

- `BP_Player_Combat.TraceSwordWindow`: 검의 세 검사 궤적 표시.
- `BP_Player_Combat.ResolveSwordContact`: 실제 접촉 지점 표시와 이펙트 축소.
- `BP_Boss_Crunch.EventGraph`, `TraceOtherHand`: 주 공격 손과 보조 손의 실제 판정 표시.
- `AM_Sword_Attack_1`~`4`: 연계·회피·종료 Notify와 블렌드 조정.
- `Tools/ApplyCombatReadabilityPolish.py`: 재현 가능한 에디터 변경 절차.
- `Tools/TestCombatReadability.py`: 실제 입력, 타격별 예약, 피격, 구르기/방어 복귀, 실행 화면 검사.

백업은 `/Game/BossArena/Backup/*_PreCombatReadability_20260929`와 `/Game/BossArena/Player/Animation/SwordShield/Backup/AM_Sword_Attack_*_PreFasterCombo_20260929`에 저장했다. 기존 작업을 포함한 수정 전 스냅샷이다.
