# 보스 런타임 오류와 공격 판정 종료 수정 (2026-09-30)

## 원인과 수정

- `BP_Boss_Crunch.UpdateSlamMotion`은 일반 전투 중에도 매 프레임 호출되면서 비어 있는 `ActiveAction.ActionId`를 읽었다. 실행 전에 `ActiveAction`의 유효성을 검사하도록 연결했다. `TracePhysicalStrike`도 같은 검사를 통과한 경우에만 행동 데이터와 몽타주를 읽고, 유효하지 않으면 열린 판정을 닫는다.
- `BP_Player_Combat.TryEnterDodge`는 `bInvincible=true` 이후 `OnIFrameEnd` 타이머의 실행선이 끊겨 있었다. 타이머를 실제 구르기 실행 경로에 연결해 `IFrameDuration`(현재 0.433초) 뒤 무적을 끈다.
- 공격 알림이 손의 타격 동작이 끝난 후까지 남아 있던 휩쓸기와 콤보 마지막 타에서 늦은 접촉이 가능했다. 행동 데이터의 `HitWindowEnds`를 현재 타격 번호로 읽고, 몽타주 시간이 끝점을 지나면 `bPhysicalStrikeOpen`을 닫아 손 궤적 검사를 중단한다. 애니메이션 알림의 길이는 그대로이며, 피해 검사만 더 일찍 끝난다.

## 판정 종료 데이터

`HitWindowEnds`의 단위는 **몽타주 시간(초)**이다. 콤보 배열은 각 타격의 `PhysicalStrikeIndex` 순서와 같다. 현재 재생 속도는 0.6이므로 실제 전투 시간은 몽타주 시간 차이를 0.6으로 나누어 해석한다.

| 행동 | 종료 시점 |
|---|---|
| 왼손 | 0.720 |
| 오른손 | 0.320 |
| 어퍼컷 | 0.300 |
| 휩쓸기 | 0.680 |
| 잽·잽·훅 | 0.720 / 1.253333 / 2.447 |
| 가드 브레이크 | 0.600 |
| 슈퍼맨 펀치 | 0.780 |

휩쓸기 손은 몽타주 0.44~0.60초에 크게 가로지르고 0.68초 무렵에는 회수 동작이다. 콤보의 마지막 훅도 2.447초 무렵부터 회수 동작이다. 이 두 기술의 기존 판정 알림은 각각 1.00초, 2.7667초까지 열려 있었다. 나머지 끝점은 기존 알림 끝과 동일하다.

## 확인 결과와 남은 조정

- 세 블루프린트(`BP_Boss_Crunch`, `BP_Player_Combat`, `BP_BossActionDefinition`) 컴파일: 오류 0, 경고 0.
- 수정 후 PIE 로그에 `ActiveAction` 접근 오류가 새로 나타나지 않았다. 수정 전 로그의 마지막 반복 오류는 12:42:41에 기록되어 있다.
- PIE에서 휩쓸기 몽타주 0.60초에는 물리 판정이 열려 있고, 0.75초에는 닫히며 플레이어 체력은 유지됐다.
- 이동 구르기 시작 직후 `ActionState=DODGE`, `bInvincible=true`; 타이머 경과 후 `bInvincible=false`를 확인했다.
- 실제 플레이 체감은 거리·방향·프레임률별로 추가 조정할 수 있다. 특히 휩쓸기의 좌우 구르기 대응과 가드 브레이크의 접촉 시점은 플레이 테스트로 확인해야 한다.
