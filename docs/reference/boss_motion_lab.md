# 크런치 모션·판정 테스트 씬

맵: `/Game/BossArena/Maps/Lvl_BossMotionLab`

전용 맵에서 플레이어와 크런치를 마주 보게 배치했다. 오른쪽 패널은 선택한 원본 시퀀스, 실제 HFSM 상태, 양쪽 체력, 손 공격 창, 적중 여부, 플레이어에게 적용된 피해 이벤트 횟수와 누적 피해를 보여준다. 노란 구체는 닫힌 손 판정, 빨간 구체는 열린 손 판정, 청록색 캡슐은 플레이어 피격 범위다.

## 조작

| 키 | 기능 |
| --- | --- |
| `1`–`9` | 실제 보스 행동 1회 요청. 현재 전투 몽타주와 공격 판정을 사용한다. |
| `Z` / `X` / `V` / `B` | 거리 170 / 230 / 380 / 700 cm로 재배치하고 체력을 복구한다. |
| `R` | 현재 거리에서 위치·체력을 초기화한다. 다운·피격 반응이 끝난 뒤 누른다. |
| `[` / `]` | 원본 시퀀스 목록에서 이전 / 다음 모션 선택. |
| `O` | 선택한 원본 시퀀스를 단독 재생한다. 공격 피해는 발생하지 않는다. |
| `C` | 조사 핵심 21개와 원본 폴더의 131개 시퀀스 목록 전환. |
| `T` / `Y` | `Combo_01/02_Slow → 해당 Recovery` 연속 미리보기. |
| `U` / `I` | `DashingCross_Start → DashingCross → Recovery_Hit/Recovery` 연속 미리보기. |
| `H` | 손 구체 판정과 플레이어 캡슐 표시 전환. |

`1`–`9`의 현재 연결은 순서대로 Combo 01, GutPunch, Combo 03, 양손 휩쓸기, Jab→Jab→Hook, GuardBreak, DashingCross, 접근, JumpSlam이다. GutPunch와 GuardBreak는 같은 공격 몽타주를 사용한다. `8`은 공격 애니메이션이 아닌 접근 행동이다.

## 확인 방법

1. 맵을 열고 **Play**를 누른다. 오른쪽 패널에서 `HFSM Boss.Combat.Ready`와 양쪽 체력을 확인한다.
2. `Z`를 누른 뒤 `1`을 눌러 근접 접촉을 본다. 손 구체가 빨간색으로 바뀌는 순간과 플레이어 캡슐의 교차, `hit YES`, 피해 이벤트 횟수, 체력 감소를 함께 확인한다. `1`번 행동의 설정 피해는 110이므로 이벤트가 두 번 잡히면 중복 적용을 의심할 수 있다.
3. 피격 반응이 끝나면 `R`로 복구하고 `X`·`V` 거리도 비교한다. 맞지 않는 거리에서는 `hit no`와 체력 유지가 보여야 한다.
4. `[`·`]`와 `O`로 원본 모션을 본다. 특히 `Ability_Combo_03`의 높은 타격, `Ability_Hook_Empowered`의 휩쓸기, `Slow` 모션의 속도와 손 높이를 비교한다.
5. `T`·`Y`·`U`·`I`로 회복과 대시 시작 구간의 연결감을 본다. 이 네 개는 아직 실제 패턴 연결이 아니므로 피해가 없다.

이 씬은 현재 패턴을 분리해 검증하고 신규 모션 후보를 고르는 용도다. 원본 시퀀스 미리보기에서 좋은 모션을 찾더라도 실제 보스 공격으로 채택하려면 몽타주 구성, 접촉 프레임 측정, 판정 창, HFSM·Utility AI 후보를 별도로 결정해야 한다.

## 현재 발견한 판정 문제

2026-10-02 PIE에서 피격 반응이 끝나고 체력 320을 확인한 뒤, 170cm에서 `1`번 행동을 한 번 요청했다. `DA_Attack_Left`의 설정 피해는 110이지만 피해 이벤트가 **2회**, 누적 피해가 **220**으로 표시되고 플레이어 체력은 100이 됐다. 이 중복 적용 원인은 아직 보스 공격 블루프린트에서 수정하지 않았다. 손 판정 창과 기존 피해 경로를 이 씬으로 비교할 다음 과제다.
