# 승인된 DS3 조작·카메라·판정 작업

2026-09-29. 최신 승인 범위: 플레이어, 카메라/락온, 공격/피격 판정.

### 포트폴리오 설명용 실행 흐름

1. AI는 기존 방식으로 공격을 선택한다.
2. 선택한 몽타주가 타격 구간에 들어가면 Notify가 물리 타격 번호와 판정 창을 연다.
3. 매 프레임 실제 손/검 위치와 이전 위치 사이를 Sweep한다.
4. 무적·벽 가림·같은 타격의 중복 여부를 확인한다.
5. 피해를 전달하고 해당 두 캐릭터만 잠깐 정지한다. 애니메이션 이벤트도 함께 멈추므로 타이밍이 어긋나지 않는다.
6. 판정 종료·연계/회피 취소·회복은 각 애니메이션 이벤트가 처리한다.

320cm 정면 정지 fixture의 실제 피해: 왼손 110, 오른손 0, 어퍼컷 110, 훅 양손 0, 3타 105(40+65), 가드 브레이크 0, 돌진 0.
이는 모든 패턴이 320cm에서 맞는다는 합격 기준이 아니다. 물리 볼륨을 손 위치에 맞춘 결과이며, 위/옆으로 지나가는 실제 모션과 기존 AI 선택 거리의 차이는 남아 있다.

## 남은 차이와 재현 한계

1. 320cm 정면 정지 시험에서 오른손 잽, 가드 브레이크, 돌진 등의 주먹이 작은 플레이어 몸체 옆/위로 지나가는 경우가 있다. 판정 창이 늦는 문제와 모션의 실제 빗나감은 구분한다. AI 거리 선택이나 에셋 변경으로 이를 숨기지 않는다. 모션·공격 거리 변경은 현재 범위의 허용 여부를 별도로 검토해야 한다.
2. 군다 창/발차기 DmyPoly를 Crunch 주먹에 복사하는 것은 올바른 변환이 아니다. 현재 볼륨은 Crunch 체형 기준이다.
3. DS3 원본 카메라 선택 경로·보간 공식·전체 HKS 조건과 Root Motion은 확정되지 않았다. 현재 동작을 DS3 완전 복제로 표현하지 않는다.
4. 기존 일반 피격 방향/강도 및 다운·기상만 사용한다. 강인도/그로기 체계는 추가하지 않는다.
5. 이전 작업의 미커밋 파일이 많아서 무관한 변경을 일괄 커밋/롤백하지 않는다. 이번 작업 이전 Blueprint와 변경한 모션의 백업은 `/Game/BossArena/Backup`에 있다.

## 저장과 미완료 기준

에셋 변경은 Unreal Editor에서 저장했다. 이번 마일스톤 커밋은 적용/검증 도구·원본 판독 도구·보고서·작업 지침만 대상으로 한다. 이전 작업과 섞여 있는 Blueprint 및 에셋 변경은 작업 트리에 보존한다.
`ApplyApprovedDS3.py`는 이번 에디터 세션의 그래프 편집 기록을 사용하므로 새 체크아웃에서 자동 재실행하는 설치 도구가 아니다.

원본 HKX 곡선과 5% 일치, 동일 조건의 DS3 화면 위치와 5% 일치, 원본 HKS 전체 예약 조건의 일치는 아직 검증하지 못했다. 따라서 모든 계획 항목이 DS3 원본 기준으로 완료되었다고 보고하지 않는다.
