# Crunch 연계 재조준: 기획 의도와 PIE 확인

이전에는 첫 주먹의 판정이 열리면 회전이 완전히 멈췄고, 콤보의 다음 주먹을 준비하는 `Link`에서도 계속 잠겼다. 그래서 플레이어가 첫 주먹을 피한 뒤 옆으로 이동하면 Crunch가 이미 지나간 자리를 향해 다음 주먹을 내미는 인상을 줬다.

현재 규칙은 **주먹 하나와 전체 패턴을 구분한다.** 근접 공격의 `Windup`에서는 목표를 바라보고, 주먹이 나가는 `Active`에서는 35°/초로만 작은 방향 보정을 한다. `Link`에서는 다음 주먹을 위해 다시 바라본다. 마지막 타격이 끝난 `Recovery`에서는 방향을 돌리거나 새 공격을 고르지 않는다. 슈퍼맨 펀치와 점프의 `Active`는 이 보정에서 제외해 시작한 궤도를 유지한다. 따라서 회피가 다음 주먹의 의도적인 헛침을 보장하지는 않지만, 현재 주먹을 갑자기 뒤로 꺾어 맞히지도 않는다.

`Tools/TestBossReaim.py`는 콤보를 실행하면서 플레이어의 위치를 첫 타격과 연계·회복 구간마다 바꿔 회전량을 기록한다. 2026-10-04 PIE 시나리오 `20261004T085429Z-D1FE9999`가 통과했다. 0.5배 시간 배율에서 첫 타격 중 약 **3.96°**, 첫 연계의 0.8초 동안 약 **54.74°**, 회복 시작 0.3초 동안 **0°**를 측정했다. 짧은 전진이 있는 근접 콤보의 `Windup`에도 회전 허용값이 켜진 것을 확인했다. 이전 정상 속도 시험은 `Active`가 한 프레임만 관측되어 회전량 판정에 쓰지 않았다.

이 시험은 회전 상태를 분리해 확인한 것이다. 실제 구르기 입력으로 각 기술의 회피 가능성과 마지막 판정 뒤 플레이어의 2–3타 반격을 모두 입증한 시험은 아니다. 제출 영상에는 첫 주먹 회피 → 다음 주먹 전 재조준 → 전체 패턴 종료 후 반격을 이어서 보여주고, 각 기술의 체감과 손 접촉을 추가 확인한다.
