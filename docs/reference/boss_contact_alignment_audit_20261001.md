# Crunch 주먹 접촉과 판정 정렬 (2026-10-01)

## 영상에서 시작한 문제

`Battle - 언리얼 에디터 2026-10-01 14-03-41.mp4`의 밀착 교전에서는 보스가 옆으로 팔을 돌리는 동안 플레이어의 체력이 줄었다. 주먹이 몸에 닿는 느낌을 먼저 고쳐야 하므로 행동 선택 점수보다 **모션, 손의 위치, 판정 프레임**을 확인했다.

## 측정에서 바로잡은 것

- 보스 메시의 상대 Yaw는 `-90°`다. 원본 애니메이션의 `+Y`가 보스 액터의 전방이다.
- 기존 `Tools/TestSoulsHits.py`의 보스 배치 Z 오프셋 `+108cm`는 보스의 발을 플레이어보다 약 **55cm** 높게 띄웠다. 이 상태에서 얻은 바디 펀치와 어퍼컷의 미적중 결론은 **무효**다. 이제 두 캡슐의 스케일 적용 반높이 차이로 발 높이를 맞춘다.
- 기존 오른손 물리 판정은 `hand_slide_r`에서 얻은 긴 구간을 추적했다. 거리 240cm, `AM_Boss_GutPunch` 몽타주 0.455초의 실제 `hand_r` 소켓은 플레이어에서 약 `(99,-39,144)cm`에 있었지만, 추적 구간의 앞끝은 약 `(16,-35,153)cm`까지 뻗었다. 이 구간은 보이는 주먹보다 먼저 플레이어 캡슐에 닿을 수 있었다.
- 바디 펀치를 올바른 발 높이에서 재생하면 기존 판정 구간은 0.40초부터 접촉한다. 그러나 정면 Yaw 180°에서는 화면의 주먹이 플레이어 왼쪽을 스친다. Yaw를 목표 방향에서 15° 왼쪽으로 두면 0.45초의 `hand_r` 소켓이 플레이어 상체 정면 약 `(25,0,143)cm`로 온다.
