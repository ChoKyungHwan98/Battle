# 멀미를 줄이는 고정 거리 락온 카메라

2026-09-29. 사용자의 최신 요구: 더 멀리 보이고, 락온 중 확대·축소하지 않으며 플레이어·Crunch 전신·주변 바닥을 함께 읽는다. DS3를 참고한 구조에 **Battle 전용 편안함 설정**을 적용한다. 아래 650cm와 보간 5는 원작 추출값이 아니다.

근접/중거리 캡처에서 보스 상체는 중앙보다 위, 플레이어 몸 중심은 하단에 놓이며 발과 바닥이 보인다. 이는 캡처한 상황의 확인이며 모든 모션의 화면 경계를 보장하는 수치가 아니다.

## 첨부 기획과의 관계

Chest 표식, 플레이어/적 수직 구도, 회전 보간, 상태별 공격 방향 고정은 현재 구조를 사용한다. 첨부의 거리별 확대·축소 예시는 사용자의 고정 거리 요구에 따라 적용하지 않는다. 단일 보스의 기존 획득 조건과 이동·조작키를 유지한다.

카메라 보간과 독립적인 Target-relative 이동을 추가로 시도했으나 BuildGraph의 미지원 `self` 형식과 SelectObject 입력 핀 이름 연결에서 두 번 실패했다. AGENTS.md의 2회 실패 중단 규칙에 따라 이번 추가 시도는 중단했다. 생성한 9개 노드만 삭제하고 기존 Move의 카메라 Yaw 배선을 복구·컴파일·저장했다. 따라서 이동 좌표계 개편은 이번 결과에 포함되지 않는다. 다중 타깃 선택/전환이나 시선 가림 유예도 이번에 새로 구현한 기능은 아니다.
